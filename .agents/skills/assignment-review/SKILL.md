# Submission Review

Check:

- test cases
- automation strategy
- automated scenarios
- manual scenarios
- Page Object Model
- fixtures
- external test data
- .env.example
- README
- observations
- screenshots/traces/videos
- Chromium
- Firefox
- WebKit
- mobile execution
- TypeScript errors
- Git history
- .gitignore
- no credentials committed

Run appropriate verification commands.

1. Complete
2. Missing
3. Broken
4. Recommended before submission
